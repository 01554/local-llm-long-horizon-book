## 要件一覧

### 1. フィールド管理

**Requirement 1.1**: システムは、幅 W x 高さ H のグリッドベースのフィールドを提供しなければならない。

- 受け入れ基準:
  - フィールドサイズは幅75 x 高さ26であること
  - フィールドは上下左右に壁を持つこと
  - フィールド内の各マスは、空、自機、的、弾のいずれかの状態を持つこと

**Requirement 1.2**: システムは、フィールドの上下に表示領域を設けなければならない。

- 受け入れ基準:
  - フィールド上部にタイトル行を表示すること
  - フィールド下部にスコア行と状態表示行を表示すること（2〜3行）
  - 自機がターミナルの最下端に張り付かないこと

**Requirement 1.3**: システムは、ターン制のゲーム進行を提供しなければならない。

- 受け入れ基準:
  - システムは `tick()` 関数呼び出しで 1 ターン進行すること
  - `tick()` 関数はテスト容易性のため同期的に動作すること
  - ゲームループはタイマーで `tick()` を定期呼び出しすること

---

### 2. 自機操作

**Requirement 2.1**: システムは、自機をフィールド最下行に配置しなければならない。

- 受け入れ基準:
  - 自機の初期位置はフィールド最下行の中央列であること
  - 自機は「==A==」（5マス幅）として表示されること
  - 自機は常にフィールド最下行に固定されること

**Requirement 2.2**: システムは、A/D キー入力で自機を 1 マスずつ移動させなければならない。

- 受け入れ基準:
  - A キー入力で自機は左に 1 マス移動すること
  - D キー入力で自機は右に 1 マス移動すること
  - 自機は壁を超えて移動できないこと

**Requirement 2.3**: システムは、下向き弾が自機位置に到達した場合、ゲームオーバーとしなければならない。

- 受け入れ基準:
  - 下向き弾（v）が自機の5マス幅のいずれかに到達した場合、ゲームオーバーとなること
  - ゲームオーバー時、スコアが表示されること
  - ゲームオーバー後、ゲームを再開できること

---

### 3. 弾の発射

**Requirement 3.1**: システムは、スペースキーで上向き弾（^）を発射できなければならない。

- 受け入れ基準:
  - スペースキー入力時、上向き弾（^）が生成されること
  - 弾は自機の 1 マス上に生成されること
  - 弾は毎ターン進行方向に 1 マス移動すること

**Requirement 3.2**: システムは、スペースキーのトグルで自動連射を切り替えなければならない。

- 受け入れ基準:
  - スペースキーを1回押すと連射モードが開始され、3ターンに1発の間隔で自動的に弾が発射されること
  - 連射モード中にスペースキーをもう1回押すと連射が停止すること
  - 連射間隔は tick 数で管理されること

---

### 4. 弾と的の衝突（分裂）

**Requirement 4.1**: システムは、上向き弾が的に命中した場合、左右に分裂しなければならない。

- 受け入れ基準:
  - 上向き弾（^）が的（@）に命中した場合、弾は消滅すること
  - 命中位置に左向き弾（<）と右向き弾（>）が生成されること
  - 命中した的は消滅すること
  - 分裂時、反射回数は 0 にリセットされること

**Requirement 4.2**: システムは、横向き弾が的に命中した場合、上下に分裂しなければならない。

- 受け入れ基準:
  - 左向き弾（<）または右向き弾（>）が的（@）に命中した場合、弾は消滅すること
  - 命中位置に上向き弾（^）と下向き弾（v）が生成されること
  - 命中した的は消滅すること
  - 分裂時、反射回数は 0 にリセットされること

**Requirement 4.3**: システムは、下向き弾が的に命中した場合、弾を消去しなければならない。

- 受け入れ基準:
  - 下向き弾（v）が的（@）に命中した場合、弾と的はともに消滅すること
  - 下向き弾は分裂しないこと

---

### 5. 壁反射

**Requirement 5.1**: システムは、弾が壁に到達した場合、進行方向を反転しなければならない。

- 受け入れ基準:
  - 上向き弾が上壁に到達した場合、下向き弾に方向変更すること
  - 下向き弾が下壁に到達した場合、上向き弾に方向変更すること
  - 左向き弾が左壁に到達した場合、右向き弾に方向変更すること
  - 右向き弾が右壁に到達した場合、左向き弾に方向変更すること

**Requirement 5.2**: システムは、反射回数を管理しなければならない。

- 受け入れ基準:
  - 壁に反射するたびに反射回数が+1 されること
  - 反射回数が 3 に達した弾は消滅すること
  - 各弾は独立して反射回数を保持すること

---

### 6. 弾同士の衝突

**Requirement 6.1**: システムは、反対方向の弾が同じマスで衝突した場合、確率判定と方向変更を適用しなければならない。

- 受け入れ基準:
  - 上向き弾（^）と下向き弾（v）、または左向き弾（<）と右向き弾（>）が同じマスにある場合、衝突とする
  - 各弾は独立に 1/2 の確率で消滅する
  - 消滅しなかった弾は時計回りに90度方向変更する（^→>、>→v、v→<、<→^）
  - 方向変更は反射回数に+1される

---

### 7. 同方向弾の合体

**Requirement 7.1**: システムは、同じマスに同じ方向の弾が存在する場合、合体させなければならない。

- 受け入れ基準:
  - 同じ方向の複数の弾が同じマスに存在する場合、1 つの弾に合体すること
  - 合体後の弾の反射回数は、元の弾の中で少ない方を採用すること
  - 合体は毎ターンの終了時に判定されること

---

### 8. 的の管理

**Requirement 8.1**: システムは、的をランダムな空きマスに出現させなければならない。

- 受け入れ基準:
  - 的（@）はフィールド内の空きマスにランダムに配置されること
  - 的は自機、弾、他の的と重ならないこと
  - 的は壁の上に配置されないこと
  - 的は最下行から上7行以内には配置されないこと（自機付近の安全地帯）

**Requirement 8.2**: システムは、時間経過とともに的の出現頻度を上昇させなければならない。

- 受け入れ基準:
  - 的の出現頻度は 30 ターンごとに上昇すること
  - 出現頻度は段階的に高くなること
  - 出現頻度の上限が設定されていること

**Requirement 8.3**: システムは、的が 0 個の場合、即座に 1 個の的をポップさせなければならない。

- 受け入れ基準:
  - フィールド上の的の数が 0 個になった場合、即座に 1 個の的が生成されること
  - 生成位置はランダムな空きマスであること

---

### 9. スコア管理

**Requirement 9.1**: システムは、的を破壊するたびにスコアを加算しなければならない。

- 受け入れ基準:
  - 的を 1 個破壊するごとにスコアが加算されること
  - スコアはゲーム中常に保持されること
  - スコアはゲームオーバー時に表示されること

---

### 10. 技術的制約

**Requirement 10.1**: システムは TypeScript (Node.js) で実装されなければならない。

- 受け入れ基準:
  - 実行環境は Node.js 22+ (--experimental-strip-types) であること
  - 外部ライブラリは使用しないこと（Node.js 標準モジュールのみ）
  - `node --experimental-strip-types src/index.ts` で実行可能であること

**Requirement 10.2**: システムは raw mode + ANSI エスケープで描画・入力を行うこと。

- 受け入れ基準:
  - 画面描画は ANSI エスケープシーケンス（`\x1b[H`, `\x1b[2J`, `\x1b[?25l` 等）を使用すること
  - キー入力は `process.stdin` を raw mode に設定して取得すること
  - 終了時に raw mode を解除し、カーソルを復元すること

**Requirement 10.3**: システムは全モジュールを個別ファイルに分割しなければならない。

- 受け入れ基準:
  - 各機能は個別の .ts ファイルに分割されること
  - 各ファイルは明確な責務を持つこと
  - 1ファイルあたり最大2タスクまで

## 用語集

| 用語 | 定義 |
|------|------|
| フィールド | 幅75 x 高さ26 のグリッド。上下左右に壁がある |
| ターン | ゲームの進行単位。`tick()` 呼び出しで 1 ターン進行 |
| 反射回数 | 弾が壁に反射した回数。3 回で弾は消滅 |
| 分裂 | 弾が的に命中し、複数の弾に分割する現象 |
| 合体 | 同じ方向の弾が同一マスで 1 つに統合される現象 |
| 安全地帯 | 最下行から上7行以内の領域。的は配置されない |
| ゲームオーバー | 下向き弾が自機に命中した状態 |
